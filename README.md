# Best of Yamhill County nominations

Public nomination page for Best of Yamhill County, presented by YamCo Vibe.

Sip. Savor. Explore.

This is a static site (`index.html` and `assets/`) with no build step. Nominations are stored in the YamCo Vibe app database. The page reads the nomination open and close dates from the database, so changing those dates does not require a redeploy.

After DNS is pointed at this site, the page will live at [nominate.yamcovibe.com](https://nominate.yamcovibe.com).

Optional URL parameters:

- `?award=wineries` (or another award slug) preselects an award
- `?contest=best-of-2027` selects a contest (this is the default)
